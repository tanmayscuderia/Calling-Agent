# API Key

Source: https://docs.sarvam.ai/conversations/settings/api-key

Manage API credentials for Voice Agents integrations.

1.  Open **Settings → API Key** in the dashboard.
2.  Create or rotate a key as needed.
3.  Use the key for API, SDK, and server-side integrations.
4.  Revoke keys that are unused or potentially exposed.

Never embed production keys in client-side widget code or public repositories. Prefer server-side proxies for browser apps.
