# Overview

Source: https://docs.sarvam.ai/conversations/deploy/overview

**Deploying** means taking the agent you built and tested and making it reachable by real people — over the phone, on your website, or from your own code.

Open **Deploy** from the left sidebar of Voice Agents to get started.

Before you deploy, make sure your agent is [built and tested](https://docs.sarvam.ai/conversations/quickstart) and its version is committed. Deploying always uses a committed version, not your unsaved draft.

There are two main ways to go live: **over the phone** (telephony) or **on the web / in code** (a website widget or the API).

[

Phone Numbers

Set up phone calling — connect your own provider or rent a number from Sarvam. This is the foundation for both inbound and outbound calls.







](https://docs.sarvam.ai/conversations/deploy/telephony)[

Inbounds

Have your agent answer incoming phone calls.







](https://docs.sarvam.ai/conversations/deploy/inbounds)[

Campaigns

Have your agent call a list of contacts, on a schedule you set.







](https://docs.sarvam.ai/conversations/deploy/campaigns)[

Deploy with Code

Add a call button (widget) to your website, or integrate with the API and SDK.







](https://docs.sarvam.ai/conversations/deploy/deploy-with-code)

## Where should I start?

[1](https://docs.sarvam.ai/conversations/deploy/overview#you-want-your-agent-to-answer-incoming-calls)

### You want your agent to answer incoming calls

First, get a phone number: [connect your own telephony provider](https://docs.sarvam.ai/conversations/deploy/telephony/bring-your-own) or [rent a number from Sarvam](https://docs.sarvam.ai/conversations/deploy/telephony/rent-from-sarvam). Then create an [Inbound deployment](https://docs.sarvam.ai/conversations/deploy/inbounds), which links that number to your agent so any call to it is answered by the agent.

[2](https://docs.sarvam.ai/conversations/deploy/overview#you-want-your-agent-to-call-a-list-of-people)

### You want your agent to call a list of people

First, get a phone number ([your own provider](https://docs.sarvam.ai/conversations/deploy/telephony/bring-your-own) or [rented from Sarvam](https://docs.sarvam.ai/conversations/deploy/telephony/rent-from-sarvam)). Then create a [Campaign](https://docs.sarvam.ai/conversations/deploy/campaigns/create-campaign): upload your contact list, set a calling schedule, and the agent dials through it automatically.

[3](https://docs.sarvam.ai/conversations/deploy/overview#you-want-a-call-button-on-your-website)

### You want a call button on your website

A widget is a small call-or-chat button you add to your site so visitors can talk to your agent. Copy the ready-made snippet of code from [Deploy with Code](https://docs.sarvam.ai/conversations/deploy/deploy-with-code#embed-the-agent-widget) and paste it into your web page — no phone number needed.

[4](https://docs.sarvam.ai/conversations/deploy/overview#you-want-to-integrate-with-your-own-code)

### You want to integrate with your own code

For developers: use [Deploy with Code](https://docs.sarvam.ai/conversations/deploy/deploy-with-code) to start sessions, stream voice over WebSocket, and build custom integrations with the API and SDK.
